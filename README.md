JobsWeb

JobsWeb is a web application designed to accurately match job seekers with companies based on their needs, providing relevant results for both companies looking to recruit employees and job seekers looking for suitable job opportunities.

Features
User registration and login
Support for two types of users:
Personal users
Company users
Companies can create and manage job positions
Job seekers can view available job positions
Job seekers can apply for jobs
Companies can view candidates who applied for their positions
Job information is stored in a MongoDB database
Technologies
HTML
CSS
JavaScript
Node.js
Express.js
MongoDB
Mongoose
Project Structure

The project contains a frontend built with HTML, CSS and JavaScript, and a backend built with Node.js and Express.js.

The backend communicates with MongoDB using Mongoose and provides API endpoints for user authentication, jobs, and applications.
